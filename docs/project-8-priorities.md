## 第一个实验候选

问题：在相同调用预算下，只优化 Plan-Execute Agent 的 planner 提示词，能否提高场景成功率？

- 对照：原始 planner 提示词与优化后的 planner 提示词。
- 固定项：执行与评分代码、模型及版本、场景集合、调用预算。
- 指标：成功率、总耗时、token 用量和调用成本。
- 数据：优化集与测试集分开；测试集不参与提示词选择。

这是待评估的候选问题。完成论文阅读和基础运行后，再确定实验范围。

## 复现阶段

1. **基础流程**：跑通公开场景，确认环境、工具和评分可用。
2. **基线实验**：固定配置，在一组场景上测量原始 Agent。
3. **论文实验**：取得对应代码、数据划分和配置后，复现 GEPA 优化与测试结果。

公开场景运行成功，仅能证明基础流程可用。论文复现还需要核对实验配置和结果。
