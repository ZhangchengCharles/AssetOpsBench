# Project Context

This repository is used for HPML Fall 2026 Project 8 (Dhaval_8): **Prompt Harness: Automated Prompt and Harness Optimization for Industrial Agents**.

The project studies prompt and harness optimization for AssetOpsBench agents with DSPy and GEPA. The scope includes component ablations, reflector and budget comparisons, held-out evaluation, and rollout throughput optimization.
